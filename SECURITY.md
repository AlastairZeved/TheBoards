# Security Policy

Zeved Boards is a client-only, offline-first PWA with no backend and no
accounts — all board data lives in the browser's IndexedDB and never
leaves the device.

## Reporting a Vulnerability

If you find a security issue, please open a
[GitHub Security Advisory](https://github.com/aboveaveragerob/TheBoards/security/advisories/new)
rather than a public issue, so it can be assessed before details are
public. Include steps to reproduce and the affected version (the `sw.js`
`CACHE` string, e.g. `zeved-boards-v74`).
